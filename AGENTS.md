# MoonAtlas

The reusable algorithms belong in the root MoonBit package. Browser code handles
file selection, presentation and local persistence; never replace graph decisions
with a JavaScript implementation. Keep input data local.

Use block-style MoonBit declarations. Run `moon info`, `moon fmt`, tests on JS and
Wasm GC, and the JavaScript integration tests after relevant changes. Do not claim
user adoption, contest eligibility or package publication without evidence.

User data and raw experiments belong outside the repository or in private-data/.
