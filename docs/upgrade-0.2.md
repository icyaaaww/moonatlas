# 升级到 MoonAtlas 0.2

原项目 JSON 无需转换，直接用新版“打开项目文件”载入。
若旧版窗口里还有未下载的整理，请先点击“保存项目”，再切换新版。

## 体验新增功能

1. 打开 `MoonAtlas.html`，点击地图工具栏的放大/缩小或“适合宽度”。点击主题旁的“聚焦”，暂时只看这一组资料；可以退出聚焦回到全局。
2. 地图上的虚线来自文档中的显式链接。点击虚线可查看引用所在原文；连线太多时可关闭。
3. 修改一篇资料的显示名或主题，再点击顶部“撤销”“重做”。归并规则、导入更新、文档移出和基线调整也支持撤销。
4. 打开“本机自动保存”，阅读提示后开启。等到显示“已保存到本机”，关闭重开同一文件/地址，选择恢复草稿。
5. 打开交付包中的 `章节对比示例.json`，进入“更新记录”，点击“查看章节变化”，并排查看前后原文。

## 保存方式

本机草稿用于日常恢复；下载的项目 JSON 用于迁移与备份。草稿只存于当前浏览器、当前应用地址，
不跨浏览器同步。清理浏览器数据、无痕模式、移动 HTML 文件或换用别的端口都可能影响恢复。

草稿只保留当前一个资料集；切换项目前会提醒下载备份。同一份草稿在多个窗口被修改时，
旧窗口会暂停自动保存，请先下载各窗口的项目文件，再决定恢复哪一份。

撤销最多 20 步，较大项目受缓存上限限制。关闭页面、切换项目或恢复草稿后撤销历史清空。
清除浏览器草稿不能撤销，当前窗口中的内容仍可下载。

## 对比边界

章节比较仍以原文标题配对；改名的标题按新增/移除处理，重复标题按出现顺序配对并给出提示。
它不会自动判断两段资料表达的知识是否相同，也不会把文档引用当作语义关联。
