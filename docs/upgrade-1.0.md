# MoonAtlas 1.0 使用与迁移指南

版本日期：2026-10-15。离线应用只在本机处理 Markdown/TXT；无需账号、服务器或 API Key。

## 第一次使用

1. 解压离线包，双击 `MoonAtlas.html`。首次打开显示空白首页，不自动载入示例。
2. 选择“体验示例”熟悉地图与原文；示例是虚构资料。准备自己的资料后，选择“导入自己的资料”或顶部“导入文件夹”。
3. 查看导入预览：新增、覆盖修改、移出、重命名、内容未变和跳过文件分别列出。PDF、Word 等文件被跳过，格式无效的 Markdown/TXT 则会中止整个导入。
4. 搜索关键词，点击命中片段，地图会展开对应文档，右侧定位准确原文行。标题、主题等元信息命中显示“文档信息”，不伪造正文行号。
5. 在地图中“批量分类”，选中文档后设置共同主题；或到“知识库体检”逐项核对，记录已处理/忽略及原因。操作只改变项目，不改写源文件。
6. 保存并验证备份。建议先用少量资料完成一次恢复，再导入整个资料夹。

## 更新资料：合并还是替换

| 场景 | 选择 | 结果 |
| --- | --- | --- |
| 只选了几篇新增/修改文件 | 合并新增 / 更新 | 保留未选中的文档；同路径内容被更新 |
| 选择完整的新资料目录 | 以本次文件替换资料集 | 未出现在本次目录中的文档会移出项目，需额外勾选确认 |
| 选错文件或仍在读取 | 取消 | 当前项目不变 |
| 已确认导入但想恢复 | 撤销 | 一步撤销该次导入，限当前窗口的历史缓存 |

改名识别仅适用于移除/新增集合中唯一且内容完全一致的文件。改名同时修改内容会显示为新增与移出。
地图和“更新记录”始终对照保存的基线；导入预览则对照当前资料。核对更新后可主动重设基线。

## 正确备份与恢复

1. 点击“保存项目”或“备份与恢复 → 下载完整备份”，将 JSON 保存到自己的资料目录。
2. 界面显示“已发起备份下载，待选回文件验证”。这是下载请求，不代表浏览器已经将文件保存完整。
3. 在“备份与恢复”点击“选回文件验证”，选中刚下载的 JSON。程序检查校验值、输入边界，并重新构建项目。
4. 只有文件与当前原文、基线、分类、归并和处理记录一致时，才显示“当前资料已验证备份”。另一份可恢复文件不会替换当前工作，也不会被算作当前备份。
5. 要真正恢复，请使用“打开项目文件”或“打开备份恢复”。当前有未保存更改时，可选择备份并验证后继续，或明确放弃更改。

新备份带 SHA-256 校验值，用于发现意外修改和损坏；它不是加密或来源真实性证明。
JSON 和分享 HTML 包含完整原文与旧基线；分享前确认其中内容适合接收者。
备份验证不会写回磁盘文件，也不提供后台同步。

## 从 0.1 / 0.2 / 0.3 升级

1. 在旧版下载项目 JSON，保留这份原始备份，不依赖浏览器草稿迁移。
2. 用 1.0 打开 JSON。v1 格式仍兼容；没有校验值的旧文件会明确提示，仍会完成结构校验和项目重建。
3. 抽查几篇文档的原文、分类、基线和处理备注。0.1/0.2 没有处理记录时，按空记录恢复。
4. 下载 1.0 备份并选回验证，再开始编辑。原始旧版备份可继续保留。

应用版本为 1.0.0，项目格式仍是 v1；两者编号含义不同。
旧版应用可能忽略新备份的校验字段，再保存时会移除该字段；更早版本还可能丢失处理记录。不建议在不同应用版本之间反复编辑同一项目。

## 本机草稿与多个资料集

本机自动保存默认关闭。主动开启后，只保存当前浏览器、当前应用路径下的一份草稿；修改成功写入后显示时间。
换浏览器、移动 HTML 到另一目录、清理浏览器数据或使用无痕窗口，可能无法恢复原草稿。
升级时 `?v=1.0.0` 查询参数不改变同一应用 pathname，但 file:// 存储仍受浏览器策略影响。

多个知识库请分别保存项目 JSON；1.0 没有多库管理器、团队同步或账号系统。
撤销历史只在当前窗口保留，最多 20 步且受缓存大小限制；切换项目或刷新后清空。

## 常见问题

- **校验失败**：当前资料不会被覆盖。重新选择未编辑过的备份，或恢复另一份已知完整的 JSON；保留损坏文件便于自行排查。
- **本机保存已暂停**：检查是否有另一标签页正在编辑，或浏览器空间是否不足。先下载并验证当前项目，再决定恢复/替换草稿。
- **导入变慢**：保留读取窗口，等待进度或取消。接近容量上限时构图与预览也可能短暂占用主线程。Windows WebKit 自动化环境曾出现约 24 秒的 35 文件冷读取，见验证记录。
- **不支持备份校验**：换到实测浏览器打开离线 HTML 或本机地址；也可先导出交互 HTML 保存当前资料。不要把任意来源的 HTML 当成安全的数据文件执行。
- **手机布局可用但无法选整个目录**：目录选择受设备和浏览器限制，可改用多文件选择或在桌面导入后分享 HTML。手机实机与 Safari 尚未认证。

输入上限和格式范围见 README；实测环境见 `validation.md`；性能记录见 `performance.md`。
